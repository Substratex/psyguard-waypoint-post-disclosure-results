# Limitations and Next Tests

## Current limitations

### Single trajectory

This is one external long-horizon runtime.

Replication is required.

### Small intervention count

PsiGuard disclosed 11 intervention turns.

This is enough for event-level comparison but not enough for broad confirmatory statistical claims.

### Temporal dependence

Adjacent Aperture evidence horizons are not independent samples.

Candidate and formal states persist across time.

Standard turn-level significance calculations therefore have limited inferential meaning.

### Intervention changes the trajectory

PsiGuard acts mid-answer and can steady the model.

The runtime after an intervention is therefore partly an interventional trajectory.

This is why the prior Aperture horizon T−1 is preferred for advance-state comparison.

### Broad candidate state

Aperture candidate state is common during holding periods.

It may be useful as a trajectory-state indicator without being sufficiently specific for intervention prediction.

## Recommended next replication

A second independent experiment should preserve the same anti-contamination structure:

1. external trajectory selected without Aperture tuning;
2. comparator coordinates withheld;
3. Aperture method/version frozen before analysis;
4. full prospective prefix replay;
5. blind lock published before comparator disclosure;
6. comparator native labels disclosed unchanged;
7. primary prospective comparison preregistered as `T−1 → action at T`;
8. exact-turn relationships treated separately from advance prediction;
9. no post-disclosure retuning;
10. results preserved as a new comparison artifact.

## Key question for replication

The most important next question is not whether every PsiGuard intervention matches Aperture.

It is:

> **Does independent intervention activity continue to occur disproportionately inside or shortly after frozen Aperture trajectory-instability / boundary episodes across additional external runtimes?**

Repeated confirmation would materially strengthen the construct-validity case for the trajectory-level measurements.
