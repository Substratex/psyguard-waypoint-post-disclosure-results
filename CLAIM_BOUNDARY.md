# Claim Boundary

This repository records the post-disclosure result of the first Waypoint T1–T275 Aperture × PsiGuard blind comparison.

It supports claims about:

- source/topology correspondence;
- frozen prospective state at each evidence horizon;
- native PsiGuard disclosure coordinates;
- temporal correspondence and disagreement between the two systems;
- operational feasibility of the comparison protocol.

It does **not** authorize claims that:

- PsiGuard is ground truth;
- PsiGuard intervention equals Aperture formal `t*`;
- Aperture predicted all interventions;
- the T2 warning is a calibrated intervention alarm;
- temporary formal `t*` states are terminal Basin Exits;
- the trajectory representation is a literal physical field;
- every Aperture metric is scientifically validated;
- the findings generalize to other models, runtimes, or tasks without replication.

The result should be described as:

> **partial prospective structural/temporal correspondence with informative disagreement in a first blind external trajectory.**
